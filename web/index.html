Web Flasher

M5Stack Basic 用ファームウェアを書き込みます。 USB ケーブルで接続し、下のボタンからシリアルポートを選択してください。

INSTALL / UPDATE

Install firmware

対象ボード: M5Stack Basic (ESP32 / 16 MB Flash)
ファームウェアは GitHub Actions でビルドされた最新の安定版です。

このブラウザは Web Serial に対応していません。デスクトップ版 Chrome または Edge を使用してください。 HTTPS 接続が必要です。GitHub Pages の URL から開いてください。

書き込み前に確認してください
・USB データ通信対応ケーブルを使用してください。
・シリアルモニタなど、同じ COM ポートを使用するアプリを閉じてください。
・初回インストール時は既存データの消去を選択できます。
・書き込み中は USB ケーブルを抜かないでください。
1. Connect USB 接続後、表示された M5Stack のシリアルポートを選択します。
2. Install Install を開始し、書き込みと検証が終わるまで待ちます。
3. Reboot 完了後にボードを再起動し、画面とセンサ状態を確認します。
