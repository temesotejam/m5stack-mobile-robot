# Hardware configuration

## Target stack

- M5Stack Basic (K001)
- BASE AAA
- Module13.2 GoPlus2 (M025-B)
- Module GNSS (M135)

The firmware is initially a hardware bring-up application. It does not issue motor or servo commands during startup.

## Shared I2C bus

M5Stack Basic uses the following I2C pins:

| Signal | ESP32 GPIO |
|---|---:|
| SDA | 21 |
| SCL | 22 |

The GoPlus2 and the GNSS module's onboard sensors share this bus.

| Device | Address | Notes |
|---|---:|---|
| GoPlus2 | 0x38 | STM32 controller |
| BMI270 | 0x68 or 0x69 | Firmware probes both addresses |
| BMP280 | 0x76 or 0x77 | Firmware probes both addresses |
| BMM150 | Internal AUX bus | Accessed through the BMI270; it is not a separate host I2C device |

M5Stack's GNSS documentation lists BMI270 at 0x69, while its sensor example uses 0x68. The firmware therefore probes both addresses instead of assuming one switch configuration.

## GNSS UART

The NEO-M9N default baud rate is 38400 bps.

| Signal | ESP32 |
|---|---|
| GNSS TX | GPIO16 (Serial2 RX) |
| GNSS RX | GPIO17 (Serial2 TX) |

Set the GNSS module's UART DIP switches so the NEO-M9N UART is routed to the host pins used by Serial2. If the switches are changed, update the pin definitions in src/main.cpp.

The GNSS receiver needs a suitable view of the sky. First position tests should be performed outdoors.

## GoPlus2

GoPlus2 uses I2C address 0x38. It has four servo channels and two DC motor channels. This project initially uses only the servo interface.

The Basic sends a register command over I2C; the GoPlus2 controller generates the servo signal. The servo signal is not generated by a Basic GPIO pin.

The driver exposes:
- setServoAngle(channel, angle) for channels 0..3 and angles 0..180 degrees
- setServoPulseWidth(channel, pulseWidthUs) for direct pulse-width commands

Neither method is called automatically. Confirm the servo type, supply voltage, current capacity, wiring and mechanical travel before a manual actuator test.

## Power and magnetic interference

- BASE AAA is treated as the M5Stack Basic power base.
- GoPlus2 has its own external DC input and internal battery. Confirm the exact supply path and servo voltage from the module documentation before connecting a load.
- Do not assume the AAA cells can supply servo or motor peak current.
- Keep the GNSS module's BMM150 away from motors, magnets, high-current wiring and other magnetic sources. The GNSS module documentation warns that magnetic interference can cause abnormal readings.
- GNSS positioning should be tested outdoors. The module's nominal positioning accuracy is about 1.5 m and its maximum navigation update rate is 25 Hz; these are not guarantees in every environment.

## Initial bring-up sequence

1. Power the Basic and confirm the display starts.
2. Check the I2C scan for GoPlus2, BMI270 and BMP280.
3. Check GNSS UART reception outdoors.
4. Compare IMU readings with the module held still and then rotated by hand.
5. Check magnetic interference with the motors and servos powered separately.
6. Only after power and wiring checks, add explicit servo test commands.
